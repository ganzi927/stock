# 40 · AI 코멘트 · 종합 전망 탭

담당 코드: `ai_commentary.py`(API 호출·프롬프트 빌더·시스템 프롬프트),
`outlook.py`(4번째 탭 조립·게시 전 검증).

**정의.** 공포탐욕지수와 각 옵션 섹션에는 API 상태와 무관한 결정론적 초보자용 해설을
항상 표시한다. KFGI는 백분위와 원자료 의미를 바꾸는 LLM 재서술 위험 때문에 결정론적
해설만 사용한다. 종합 상태도 LLM 없는 결정론적 사실 설명이다. 연구용 옵션 수치를
Claude에 전달하는 상세 해설은
`KFGI_RESEARCH_AI=1`일 때만 연구 패널 안에 추가한다.

---

## A. 호출 계약 (`generate_commentary`)

- `MODEL = "claude-haiku-4-5-20251001"`, `API_URL = https://api.anthropic.com/v1/messages`,
  헤더 `anthropic-version: 2023-06-01`.
- **REQ-AI-1 (하드 오프).** `os.getenv("KFGI_AI", "1")`가 `{"0","off","false","no"}`(소문자
  비교)면 **모든 LLM 호출을 생략**하고 `None` 반환. 비용 0.
- **REQ-AI-2.** `ANTHROPIC_API_KEY` 없으면 `None`(조용히 건너뜀). 예외 발생도 `None`
  (리포트는 계속).
- **REQ-AI-3 (결정론).** `temperature = 0`. 같은 입력 → 같은 리포트여야 "어제 대비 무엇이
  바뀌었나" 비교가 성립. (미설정 시 기본 1.0이라 매 실행 서술이 요동쳤음.)
- **REQ-AI-4 (잘림 폐기).** 응답 `stop_reason == "max_tokens"`이면 문장 중간에 끊긴
  미완성 텍스트 → 게시하지 않고 `None`.
- `max_tokens`: 섹션 코멘트 기본 1500, 종합 전망 2600(한국어 12~18문장).
- 시스템 프롬프트는 `cache_control: ephemeral`로 전송하나, Haiku 최소 캐시 단위
  (2,048토큰)보다 짧아 실제 캐시 적중은 없음(확인됨).
- 기본 실행당 호출 **0회**. `KFGI_RESEARCH_AI=1`이면 코스피200 옵션 2 +
  개별주식 옵션 2가 추가되어 최대 4회다.

## B. 시스템 프롬프트 규약 (`SYSTEM_PROMPT`) — INV-AI-1

모델 출력은 아래를 **전부** 지켜야 한다. 어기면 안전망(`_strip_markdown`)이 최소 보정.

1. 사용자 메시지의 **숫자·사실만** 근거. 숫자를 새로 만들거나 추측 금지.
2. **금지**: 매수·매도 추천 / 방향 예측 확언("오를 것이다") / "외국인은 이렇게 할
   것이다"식 미래 행동 예측 / 투자 조언으로 읽힐 문장.
3. **PoT·시나리오 확률**은 반드시 "위험중립 확률(옵션 가격에 내재된 값, 실제 확률과
   리스크 프리미엄만큼 다름)"으로 성격을 밝혀 인용. "몇 % 확률로 도달한다" 단정 금지.
4. **딜러 헤지 방향**(매수/매도, 가속/완충)은 미국시장 기준 가정 — 반드시 "이 부호
   가정이 맞다면"의 조건부. 레벨의 **위치**는 부호 가정과 무관하게 유효함을 구분해 명시.
5. 실제 투자자 매매 데이터는 "오늘 실제 이랬다"로만 인용, 미래 예측 금지.
6. 형식: 한국어 존댓말, 이모지 금지, 마크다운(`**` `#` `-`) 금지(렌더러 없이 그대로
   HTML 삽입), 완결된 문장으로 마무리.

`_strip_markdown`: 모델이 규약을 어겼을 때 `^#{1,6}`, `**bold**`, `*italic*` 기호만 제거.

## C. 프롬프트 빌더

### `build_options_prompt`
`SIGN_CONVENTION_CAVEAT` 명시 + Call/Put Wall / Zero Gamma / MaxPain / Net DEX·Vanna·
Charm(명목가치) / 상·하단 Gamma Wall / 25Δ RR / positioning_skew / 관측 레벨(이름·값·종가 대비 위치·정의·한계)
/ (있으면) KB 투자자 flow 사실 문장. 6~9문장, 딜러 헤지 방향은 조건부,
PoT는 위험중립 확률 명시 요청.

### `build_outlook_prompt` (`outlook.py`)
판단용 KFGI 구성과 각 옵션 섹션의 관측 OI·거래량만 직렬화한다. 정규월물·위클리·
삼성전자·SK하이닉스를 빠뜨리지 않고 현재 관측 차이를 초보자에게 비교하되, OI/거래량
우위를 방향성·지지/저항·딜러 포지션으로 해석하지 않는다. 소제목 없이, 존댓말,
12~18문장으로 요청한다.

### 결정론적 초보자 해설 — REQ-AI-8

- KFGI에는 일반 252거래일 백분위와 공포 방향의 역산 점수를 구분한 뜻, 추세/투심/TOTAL의 현재 조합,
  합성 포함 지표와 연구용 제외 지표의 구분을 항상 설명한다.
- 옵션의 관측 영역에는 콜/풋 OI와 당일 거래량, 각각의 비율, OI가 누적 잔량이고 거래량이
  당일 활동량이라는 차이를 항상 설명한다.
- 접힌 연구 패널에는 현재가와 Wall·Zero Gamma·MaxPain의 상대 위치, PoT·RR·포지션
  쏠림도의 읽는 법을 계산된 값으로 설명한다. 이 설명은 해당 값이 미검증 모형이며
  지지·저항·방향 예측이 아니라는 한계를 같은 블록에 표시한다.
- 위 해설은 네트워크나 `ANTHROPIC_API_KEY` 없이도 렌더링되어야 하며, 연구 모형 값은
  연구 패널 밖이나 종합 AI 입력으로 이동하지 않는다.
- 개별주식의 관찰가격·사용자 손실한도 계산기는 분리된 결정론적 UI이며 AI가
  값을 추천하거나 사용자의 입력을 해석하지 않는다(`REQ-STK-8~10`).

## D. 연구 참고용 숫자 검증 유틸리티 (`outlook.py`) — REQ-AI-5

과거 LLM 종합의 숫자 비교 유틸리티를 보존한다. 현재 기본 종합은 LLM을 호출하지 않는다.

- 레벨 숫자 정의(`_OUTLOOK_NUM_RE`): `\d{1,3}(?:,\d{3})+(?:\.\d+)?` 또는
  `\d{3,}(?:\.\d+)?`, 그리고 `>= 100`. (문장수·소수 퍼센트는 제외.)
- `_unverified_numbers(prose, prompt)`: 산문의 레벨 숫자 중, 프롬프트에 있는 어떤 값과도
  `abs(v − a) <= max(1.0, a·0.005)` (±0.5% 또는 ±1.0)를 만족하지 못하는 것.
- 과거 LLM 게시 경로에서는 불일치 산문을 폐기했다. 현재 이 검사는 종합 탭의 생성 조건이 아니다.

## E. 탭 생략 조건

`build_outlook_section`은 다음이면 `None`(탭 없음):
`fgi_facts is None` / 기준일 일치 판단용 `opt_facts` 비었음.
**REQ-AI-9.** 종합은 allowlist 관측 수치로만 렌더링하며 LLM을 0회 호출한다.
OI/거래량에서 투자자 의도·방어수요·상승 추진력을 추론하지 않는다.

## F. 수용 기준

- **AC-AI-1.** `.env`에 `KFGI_AI=0` → 리포트 정상 생성, 프로세스에서 `api.anthropic.com`
  요청 0회, 연구 AI만 생략하며 결정론적 `outlook`은 유지한다.
- **AC-AI-2.** 동일 `--as-of`로 두 번 생성 시 AI 산문이 바이트 동일(temperature 0 +
  멱등 가드).
- **AC-AI-3.** `_unverified_numbers`는 주어진 자료에 없는 숫자를 검출한다.
- **AC-AI-7.** 정상 fixture의 기본 종합은 API 호출 0회이며 stale/연구용 수치는 포함하지 않는다.
- **AC-AI-4 (⚠ 자동 미검증).** 금지 규약(투자 조언·방향 확언) 준수는 자동 검사 없음 —
  프롬프트 제약 + 수동 리뷰.
- **AC-AI-6.** `KFGI_RESEARCH_AI=0`, Claude 응답 없음인 fixture에서도 KFGI·옵션 관측
  영역·옵션 연구 패널에 각각 초보자 설명이 존재하며, 연구용 sentinel은 종합 프롬프트에
  포함되지 않는다.

## 2026-09-15 근거 감사 정정
- REQ-AI-6: 투심 낮음=평활 변동성·P/C의 과거 대비 높은 수준, 높음=낮은 수준. P/C 거래량을 순매수나 실제 헤지수요로 단정하지 않는다.
- REQ-AI-7: OI 종류별 비중을 투자자 방향성으로 해석하지 않는다. Wall만으로 헤지 방향을 생성하지 않는다. MaxPain의 전체/부분 체인을 구분하고 수렴을 예측하지 않는다.
- REQ-AI-3/AC-AI-2 정정: temperature=0도 API 재호출의 바이트 동일성을 보장하지 않는다. 멱등 가드의 파일 재사용만 동일성을 보장한다.
- REQ-AI-5: 기존 숫자 검사에 걸린 해설은 게시하지 않고 None 반환. 검사는 전체 사실 검증이 아니며 숫자의 의미·단위·종목 혼동은 별도 한계이다.
- AC-AI-5: 투심 방향 문구와 근거 없는 숫자의 게시 중단을 회귀 검증한다.
